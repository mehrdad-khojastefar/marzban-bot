# Group Modifications

## Goal

So i want to have a cli command that allows me to make group modifications. i want to be able to select some users and do some modifications, for example i want to be able to add N GB and N days to my users, i want to ban some users, and .... .
i want to be able to select them by prefix, seller and user_id. e.g: all accounts that X seleler sold, all accounts that start with PREFIX, all accounts for user user_id.
i want the bot to wait for all the changes requested by the admin and then apply all changes to accounts. i do not want to apply changes one by one. 
the cli must be user friendly.
